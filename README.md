# 物迹账本 · Wuji Ledger

在 Obsidian 里记录拥有的物品、配件和每一天的使用成本。数据保存在本地，首次打开为空账本。

## 功能

- 画廊与编辑表格，支持搜索、排序、配件关联和归档恢复。
- 记录买入价格、卖出收入、购买日期、使用天数与每日成本。
- 拖动卡片快捷归档；拖入图片快速添加物品，也支持粘贴、选图和复用封面。
- 贴纸收藏与无边框详情，将单个物品或整份账本生成为分享图片。
- 多套主题、本地动态头像、资产统计与随身看板。
- 桌面与移动端共用账本。主要界面语言为简体中文。

## 安装和使用

社区目录审核通过后，可以在 Obsidian 的「设置 → 第三方插件」中搜索「物迹账本」。

审核期间，可从 [Releases](https://github.com/southbaird/wuji-ledger/releases) 下载同一版本的 `main.js`、`manifest.json` 和 `styles.css`，放入：

```text
<vault>/<配置目录>/plugins/wuji-ledger/
```

默认配置目录为 `.obsidian`。重启 Obsidian，然后在第三方插件中启用。

通过左侧工具栏或命令面板的「打开资产台账」进入。手机上可使用命令面板或 Ribbon Actions，打开完整台账或随身看板。

添加物品后，可以在详情中添加关联配件。卖出或停用时，拖动卡片到归档区域，填写卖价和日期后确认；取消不会改变记录。

图片拖入每次添加一件物品；多张时只取第一张。网页拖图需要浏览器提供图片文件或可访问的图片地址，普通商品页面链接不是图片。

## 图片与可选 Mac 抠图

基础安装支持普通图片和已经透明抠好的贴纸，不依赖原生组件。字体已经内嵌，汇总区使用 Obsidian 提供的开源图标；没有外部字体或图标请求。

Mac 本机自动抠图是可选功能，需要 **macOS 14+、Obsidian 桌面版**，并由你手动安装 `wuji-cutout`。插件不会下载、安装或更新该组件。没有组件时不显示制作贴纸入口，普通封面不受影响。

安装方法及构建说明见 [Mac 可选组件](docs/mac-cutout.md)。Windows、Linux、iPhone、iPad 不运行该组件；iPhone/iPad 可以粘贴「照片」中已拷贝的主体。

## 计算方式

- 净花费为买入价格减卖出收入；卖价高于买价时，净花费与日成本可以为负。
- 使用天数按 Asia/Shanghai 自然日计算，购买日与结束日都计入。在用物品算到今天，归档物品算到归档日期。
- 物品整套价值包含关联配件。配件未填购买日期时，采用主物品的日期。
- 金额以人民币显示；目前不提供多币种汇率转换。

## 隐私、网络与文件访问

- 不需要账号，不收费，没有广告、遥测或分析服务。
- 记录及设置保存为插件目录下的 `data.json`，备份保存为 `data.backup.json`。用户导入的图片保存在插件目录的 `assets/user/`。
- 只有你提供远程封面地址时，才会向该地址请求图片；分享原图、生成包含远程封面的分享图片及手动抠图时，也可能请求该地址。请求会向图片托管方暴露通常的网络连接信息。插件不主动向图片服务上传图片。
- 本地选图通过系统文件选择器或拖放/粘贴读取你明确选择的文件，包括 vault 外的文件；不扫描其他文件夹。
- 可选 Mac 组件在系统临时目录中处理图片，处理后清理临时文件，最终结果保存回插件资源目录。仅在你安装组件并触发转换时运行。
- 「更新并打开手机摘要」会创建或更新 `物迹账本/随身摘要.md`；只更新带本插件标识的摘要文件。不批量改写其他笔记。
- 分享在本地生成 PNG。复制操作写入系统剪贴板；系统分享只在你主动操作后交给系统分享面板，无法使用时提供图片下载。
- Obsidian Sync、iCloud 或其他同步服务可能同步上述文件，具体取决于你的配置；本插件不提供自己的云同步。

升级前请备份 `data.json`、`data.backup.json` 和 `assets/user/`。升级只替换三个运行文件，不要删除整个插件文件夹。

## 开发

需要 Node.js 24+ 和 npm。

```sh
npm ci
npm run check
npm run lint
```

默认构建不调用 Swift，不需要 macOS；产物为仓库根目录的 `main.js` 和 `styles.css`，搭配根目录 `manifest.json` 发布。源码中没有真实账本样例，测试使用虚构数据。

可选 Mac 组件源码在 `native/WujiCutout.swift`；只有明确运行 `npm run build:native` 才会构建。它不属于市场自动安装的三个文件。
